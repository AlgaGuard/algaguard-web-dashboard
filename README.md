# AlgaGuard web dashboard

React, TypeScript, and Vite client for the platform-first development environment. It provides route-complete functional pages, Keycloak login/logout integration, REST queries, native WebSocket recovery, role-aware navigation, simulated-data labels, command/OTA progress, and accessible responsive states.

```sh
npm ci
npm run check
npm run dev
```

No hosted deployment has been performed.
